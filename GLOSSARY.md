# Глоссарий

## Урок 1 — Настройка репозитория и документов

- terminal (терминал) — окно, в котором команды вводятся текстом и выполняются компьютером
- current directory (текущая папка) — папка, в которой сейчас «находится» терминал; команды работают относительно неё
- Git (система контроля версий) — программа, которая хранит историю изменений файлов проекта
- repository (репозиторий) — папка проекта, историю которой ведёт Git; история лежит в скрытой папке `.git`
- local repository (локальный репозиторий) — репозиторий на моём компьютере
- remote repository (удалённый репозиторий) — копия репозитория на сервере, например на GitHub
- commit (коммит) — сохранённый снимок проекта с автором, датой и сообщением
- branch (ветка) — линия истории коммитов; основная ветка называется `main`
- Markdown (язык разметки Markdown) — простой способ оформлять текст символами: `#` для заголовков, `-` для списков
- .gitignore (файл исключений Git) — список файлов и папок, которые Git не должен отслеживать
- staging area (область подготовки) — место, куда `git add` собирает изменения перед коммитом
- push (отправка) — передача локальных коммитов в удалённый репозиторий
- SSH key (SSH-ключ) — пара файлов для входа без пароля: публичный ключ хранится на сервере, секретный только у меня
- GitHub CLI (`gh`) — официальная консольная программа GitHub
- Conventional Commits (соглашение о сообщениях коммитов) — формат `тип: описание`, например `docs: add project documents`

## Урок 2 — Первая программа

- Python (язык Python) — язык программирования, на котором пишем инструкции для компьютера
- interpreter (интерпретатор) — программа, которая выполняет код `.py` сверху вниз, строка за строкой
- Command Palette (палитра команд) — поиск по командам VS Code, открывается `Ctrl+Shift+P`
- status bar (строка состояния) — полоса внизу окна VS Code; показывает, например, версию выбранного Python
- path (путь) — адрес файла или папки; относительный путь отсчитывается от текущей папки
- prompt (приглашение терминала) — строка, после которой терминал ждёт новую команду
- function (функция) — именованная команда, которую вызывают со скобками, например `print()`
- string (строка) — текст в кавычках, например `"Hello"`
- traceback (трассировка ошибки) — отчёт Python об ошибке; читаем снизу вверх: тип, строка, место
- SyntaxError (синтаксическая ошибка) — код написан неграмматично; находится до запуска, не выполняется ничего
- NameError (ошибка имени) — Python не знает такого имени, например `Print` вместо `print`
- runtime (время выполнения) — момент, когда программа уже работает; ошибки этого этапа возникают на конкретной строке
